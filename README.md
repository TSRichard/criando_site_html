# 🎵 Site Música Online

Projeto acadêmico desenvolvido para a disciplina de Tecnologias para a Internet da **Universidade de Uberaba (Uniube)**.

## 📋 Sobre o Projeto

Site temático sobre música, desenvolvido em HTML5 e CSS, atendendo todos os requisitos solicitados no trabalho acadêmico.

## 🎯 Funcionalidades

- ✅ Página inicial com logotipo da Uniube e menu de navegação
- ✅ Página com links interessantes sobre música (streaming, letras, rádios)
- ✅ Galeria de imagens com tema musical
- ✅ Formulário de contato completo
- ✅ Listas ordenadas e não ordenadas
- ✅ Tabela de preços de aulas de música
- ✅ Design responsivo e centralizado
- ✅ Navegação entre todas as páginas

## 📄 Páginas do Site

| Página | Descrição |
|--------|-----------|
| `index.html` | Página inicial com logotipo da Uniube |
| `links.html` | Links para sites de streaming, letras e rádios |
| `imagens.html` | Galeria com imagens de instrumentos musicais e tabela de preços |
| `fale_conosco.html` | Formulário de contato com campos de texto, rádio, select e textarea |

---

## 📞 Formulário de Contato

O formulário da página `fale_conosco.html` contém:

- Campo de texto (nome e e-mail)
- Botões de rádio (perfil do usuário)
- Caixa de seleção (assunto da mensagem)
- Textarea (mensagem)
- Botão de envio

---

## 🎨 Estilos CSS

Foram criados dois arquivos CSS:

- `estilo_centralizado.css` - Estilo com textos centralizados (página inicial)
- `estilo_esquerda.css` - Estilo com textos alinhados à esquerda (demais páginas)
